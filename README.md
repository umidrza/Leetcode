# Leetcode Solutions

This repository contains C# implementations for various LeetCode problems.

## Structure

- `src/Definitions/` - shared model classes such as linked lists, trees, and graph nodes
- `src/Solutions/` - problem solutions grouped by topic (Array, DP, BFS, Tree, etc.)
- `Program.cs` - a small entry point used to run sample test cases

## Run the project

```bash
dotnet run
```

## Notes

- The project is organized by problem category to keep solutions easy to browse.
- Each solution file usually contains a class with the logic for one LeetCode question.
- You can modify the sample code in `Program.cs` to test different inputs.
